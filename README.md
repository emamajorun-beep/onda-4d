# Onda 4D

Videojuego retro arcade para celular que conecta **Señales y Sistemas** con **Ingeniería Multimedia**.
Proyecto de la PEF06-ODS4-26-2S del **Colectivo 4D**, Universidad Autónoma de Occidente (Cali).

Un virus llamado GLITCH llenó de ruido el Estudio 4D. Con BIT, el robot técnico, limpias el audio con filtros,
descubres el eco de una sala con convolución y anulas ruido con fasores.

## Niveles
1. **Estudio de grabación**: transformada de Fourier y filtros (pasa bajos, pasa altos, pasa banda).
2. **Sala de conciertos**: convolución y respuesta al impulso.
3. **Sintetizador**: números complejos y fasores, con cancelación de ruido.
4. **Cámara lenta**: muestreo y aliasing (en construcción).

Cada nivel tiene teoría rápida, 3 misiones, un punto de control con preguntas del banco curado por el colectivo y un reto arcade de 30 segundos.

## Jugar
Abre `index.html` en el navegador o entra a la versión publicada en GitHub Pages. No necesita instalación.
